# Clienti

## Come nasce una scheda

Non serve inserire i clienti a mano: ogni prenotazione con un telefono (o un'email) viene collegata
alla scheda del cliente, che si crea al primo contatto.

- Il **telefono** è la chiave: "333 123 4567", "+39 333-1234567" e "0039 3331234567" sono lo stesso
  cliente. I numeri senza prefisso sono considerati italiani.
- Senza telefono si usa l'**email**.
- Se il cliente esiste già si completano i contatti mancanti; il nome già in scheda non viene cambiato.
- Mentre si inserisce una prenotazione, scrivendo il nome o qualche cifra del telefono compaiono i
  clienti esistenti: scegliendone uno si vedono subito note, etichette, visite e no-show.

## Cosa contiene

|                 |                                                                               |
| --------------- | ----------------------------------------------------------------------------- |
| Contatti        | nome, telefono, email, consenso marketing                                     |
| Note permanenti | allergie, preferenze, tavolo preferito: compaiono su ogni prenotazione        |
| Etichette       | VIP, Abituale, Celiaco… o personalizzate                                      |
| Numeri          | visite, coperti, no-show, cancellazioni, ultima visita, prossima prenotazione |
| Storico         | tutte le prenotazioni, con tavolo, stato e note                               |

Le **visite** contano le prenotazioni arrivate, sedute o concluse, e quelle confermate il cui orario è
passato (molti locali non segnano "conclusa").

## Privacy

"Elimina cliente" cancella la scheda e **anonimizza** le sue prenotazioni (nome sostituito, telefono,
email e note rimossi): restano solo i numeri utili al locale. Possono farlo titolare e manager.
